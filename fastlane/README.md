# Store listing

The Google Play store listing, one folder per store language, in the layout used by fastlane
`supply` (and read by F-Droid):

```text
metadata/android/<language>/
  title.txt                 app name on the store, at most 30 characters
  short_description.txt     at most 80 characters
  full_description.txt      at most 4000 characters
  images/icon.png           512 × 512, 32-bit PNG
  images/featureGraphic.png 1024 × 500, 24-bit PNG (no transparency)
  images/phoneScreenshots/  2–8 screenshots, 24-bit PNG or JPEG
```

| Folder | Play Console language |
|---|---|
| `lt` | Lithuanian – lt |
| `en-US` | English (United States) – en-US |
| `ru-RU` | Russian – ru-RU |
| `pl-PL` | Polish – pl-PL |

In Play Console, open the app's main store listing (under *Grow users → Store presence*),
paste the texts and upload the images; *Manage translations → Add your own translations* adds
the other languages. Nothing uploads them automatically yet.

## Writing rules

- Keep the disclaimer from [docs/store-privacy.md](../docs/store-privacy.md#store-listing-disclaimer)
  at the end of every full description. The listing must not suggest the app is official.
- Use the same words as the app (`app/src/i18n/locales/`): "Mixed waste", "Packaging",
  "Glass", the menu items users have to find.
- Don't promise what the app doesn't do, and update the texts in the same pull request as a
  feature they describe.
- No emoji or ALL CAPS in the title and no keyword lists: Google Play's metadata policy
  forbids them.

## Graphics and screenshots

Everything in `images/` is generated by the scripts in [`tools/`](tools), from the app icon
(`app/assets/icon-src/`), the app's font (Manrope) and the app's own translations, so all four
languages stay consistent. Run `npm ci` in `app/` (for the font) and in `fastlane/tools/` first.

- `npm run graphics`: `icon.png` (`icon.svg` at 512 × 512) and `featureGraphic.png`, whose
  headline is the onboarding title of that language. The SVG sources are written to
  `graphics-src/`.
- `npm run capture`: takes the raw screenshots on an Android emulator (Android Studio's
  *Device Manager*, e.g. a Pixel 8) that has the app installed. It switches the emulator to a
  9:16 screen and a tidy status bar, goes through the app from a fresh start in each language
  (welcome, search for Sudervė, "All set", home, own schedule) and saves the screens to
  `tools/raw/`. `npm run capture -- lt` does one language.
- `npm run frame`: puts each raw screenshot on the green background under a caption (the
  onboarding feature texts and the *Your own schedule* title) and writes
  `images/phoneScreenshots/`.

Retake the screenshots when a screen in them changes. To install a release build on the
emulator, download the APK from the pull request's **App Android build** run (*Artifacts*) and
`adb install` it.
